# Ícones do overlay

Coloque aqui as imagens-fonte dos itens da barra.

Nomes planejados:

- `trophy.png`
- `volume.png`
- `settings.png`

Recomendação: PNG com fundo transparente e desenho branco. O overlay preserva a proporção, redimensiona cada imagem para caber em 60×60 pixels e reduz o alpha dos itens não selecionados.
